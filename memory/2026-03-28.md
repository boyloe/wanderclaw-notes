## Technical Decisions Made

- **SQLite over Postgres** — simpler for MVP, no extra infra needed on VPS
- **Prisma 7** — required `better-sqlite3` adapter (no longer uses `url` in schema.prisma)
- **NextAuth v5 (beta)** — magic link auth, no passwords
- **Playwright over OpenClaw browser tool** — runs 24/7 headlessly without needing Wanderclaw active
- **tsx for the runner** — TypeScript without a compile step, fast iteration
- **PM2** — keeps both dashboard + runner alive, survives reboots via systemd
- **Sonnet for the whole build** — agreed in brainstorm session, worth the slightly higher token cost

## Key Issues Hit & Resolved

- **Prisma 7 breaking change** — `url` in datasource block no longer supported, moved to `prisma.config.ts`
- **Two dev.db files** — migration created `prisma/dev.db` but runtime used `dev.db` at root. Fixed path in prisma singleton and seed script
- **Chromium missing libs on Ubuntu 24.04** — `libnspr4`, `libnss3`, etc. Bryan installed manually. Note: `libasound2` → `libasound2t64` on Ubuntu 24.04
- **Stripe lazy init** — can't throw at module load time in Next.js; used Proxy pattern for lazy singleton
- **Stripe API version** — installed version expected `2026-03-25.dahlia` not `2025-02-24.acacia`
- **Port 3001 conflicts** — old dev server sessions kept holding the port; had to `kill -9` the pid directly
- **tsx not globally installed** — installed as devDependency so PM2 could reference it via `./node_modules/.bin/tsx`
- **Step executor regex** — `*/` in block comments terminates JS comments early (TypeScript parser issue)
- **Plain-English step parser** — `expect "X" on page` regex needed to handle both quoted and unquoted text
