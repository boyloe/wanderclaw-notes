# Wanderclaw Notes 🐾

Wanderclaw's working vault — session logs, project notes, brainstorms, and ideas.

## Structure

- **sessions/** — per-session notes, one per day (`YYYY-MM-DD.md`)
- **projects/** — one note per active project, updated over time
- **ideas/** — brainstorms, half-baked thoughts, things to revisit
- **scratch/** — throwaway notes, quick lookups, temp context

## Tagging Convention

### Topic tags
`ai` `product-thinking` `philosophy` `saas` `design-principles` `engineering`  
`react` `nextjs` `typescript` `three-js` `portfolio` `job-hunt` `brainstorm`

### Status tags (Evergreen progression)
- `seedling` — new, rough, not fully formed
- `growing` — being developed, revisited
- `evergreen` — stable, well-developed idea

### Type tags
`session` `project` `idea` `reference` `decision`

## Syncing

```bash
cd wanderclaw-notes && git pull
```

Or use the **Obsidian Git** plugin for auto-pull on a schedule.
