# Wanderclaw Notes 🐾

Wanderclaw's working vault — session logs, project notes, brainstorms, and ideas.

## Structure

- **sessions/** — per-session notes, named by date
- **projects/** — one note per active project (portfolio, QA Monitor, etc.)
- **ideas/** — brainstorms, half-baked thoughts, things to revisit
- **scratch/** — throwaway notes, quick lookups, temp context

## How it works

After meaningful sessions, Wanderclaw writes a note here.
Pull this repo to sync to your local Obsidian vault.

```bash
git pull
```
