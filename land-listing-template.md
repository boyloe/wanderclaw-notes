# Land Listing Analysis Template

## Instructions
Paste listing data in this format, and I'll analyze & rank by fit.

---

## Listing Entry Format

```markdown
### [Property Name/Address]
- **Location:** [Town, County, CO]
- **Acres:** [number]
- **Price:** $[amount]
- **$/Acre:** $[calculated]
- **Listing URL:** [link]
- **Listing Agent:** [name] | [email/phone]
- **Elevation:** [feet] (if listed)
- **Zoning:** [if listed]
- **Utilities:** [notes on well, septic, electric]
- **Road Access:** [yes/no, description]
- **Slope/Grade:** [if mentioned]
- **Notes:** [any other relevant details]
```

## Example

### Twin Lakes Road, 15 acres
- **Location:** Leadville, Lake County, CO

## Analysis Criteria (I'll Score Each)

| Criteria | Weight | Notes |
|---|---|---|
| Budget Fit | 25% | Land price within $100k–$150k range |
| Acreage | 15% | 5–30 acres (your stated range) |
| $/Acre Ratio | 15% | $3,500–$5,500/acre optimal |
| County/Zoning | 15% | Lake County or Chaffee, modular-friendly zones |
| Utilities Feasible | 15% | Well, septic, electric likely = lower build costs |
| Road Access | 10% | Paved > gravel; critical for construction |
| **Total Score** | **100%** | 0–100 scale |

## Ranking Output

Once you paste 10+ listings, I'll produce:

1. **Summary Table** — all properties ranked 0–100
2. **Top 5 Breakdown** — detailed analysis for each
3. **Red Flags List** — zoning issues, utility challenges, etc.
4. **Next Steps** — which agents to contact, questions to ask
